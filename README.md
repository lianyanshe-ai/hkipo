# HK IPO Screener 🇭🇰

港股 IPO 智能打新评估工具 — 基于 127 只真实港股 IPO 数据回测校准的八维评分引擎。

> **2026 年回测结果**：17 个买入信号全部正确（100% 精确率），平均收益 +106.9%。

---

## ✨ 功能特点

- **八维评分体系**：认购热度、行业赛道、保荐人、基石投资者、绿鞋机制、估值合理性、市值稳定性、基础分（满分 100）
- **VETO 一票否决规则**：2 条数据驱动的 VETO 规则 + 零售狂热豁免机制
- **智能文本解析**：自动从搜索文本中提取保荐人、基石、认购倍数等关键字段
- **多模式运行**：手动输入、搜索文本解析、自动搜索 + 评分
- **回测验证**：内置 127 只 2025-2026 年真实港股 IPO 数据

## 🎯 评分体系（满分 100 分）

基于 127 只真实 IPO 数据回测校准的权重分配：

| 维度 | 最高分 | 评分逻辑 |
|------|--------|----------|
| ① 认购热度 | 40 分 | 500x+=40, 200x=36, 100x=32, 50x=28, 20x=22, 10x=16, 5x=10, 2x=5, <2=0 |
| ② 行业赛道 | 25 分 | T1 硬科技 25→T2 生医 20→T3 成长 15→T4 消费 10→T5 传统 5；热门赛道 +5 |
| ③ 保荐人 | 15 分 | T0（摩根大通/大摩/高盛）15→T1（中金/中信/瑞银）13→T2（华泰/招银）10→T3（华兴等）6→底部 3 |
| ④ 基石投资者 | 10 分 | ≥2 家白名单+占比 30-70%→10；≥1 家+占比合理→7；≥1 家→4；有基石→2 |
| ⑤ 绿鞋机制 | 5 分 | 头部稳价人=5；其他稳价人=3；无绿鞋=0 |
| ⑥ 估值合理性 | 5 分 | PE<0.7x 行业均值→5；<0.9x→3；>2x→-3；>1.5x→-1 |
| ⑦ 市值稳定性 | 5 分 | ≥500 亿=5；≥100 亿=3；≥30 亿=1；<30 亿=0 |
| ⑧ 基础分 | 5 分 | 参与即得 5 分 |

### 决策阈值

| 评分 | 决策 |
|------|------|
| ≥72 分 | 🟢 强烈建议打 |
| ≥60 分 | 🟡 建议打 |
| ≥35 分 | 🟡 谨慎观望 |

## 🚫 VETO 规则（命中即放弃）

v3.0 精简为 2 条数据驱动的 VETO 规则：

| 规则 | 触发条件 | 含义 |
|------|----------|------|
| V1 | 认购<2x + 冷门行业 + 无顶级保荐人 | 极低需求+无机构背书 |
| V2 | PE>200x + 冷门行业 + 无基石 | 极端估值+无机构锁仓 |

### 零售狂热豁免

- **条件**：认购≥500x **且** 热门赛道
- **效果**：豁免所有 VETO（数据：500x+ 认购的 IPO 胜率 100%）

## 🔍 解析字段

从搜索文本中自动提取：

- `保荐人` / `联席保荐` → sponsor
- `稳价人` → stabilizer
- `基石投资者` / `基石` → cornerstone_investors（白名单过滤）
- `占全球发售股份 XX%` → cornerstone_pct
- `绿鞋` / `超额配股` → greenshoe（自动检测 15%）
- `市值 XX 亿` → market_cap
- `行业` → industry（AI/半导体/创新药等）
- `PE` → pe / industry_pe_avg
- `超额认购 XX 倍` / `孖展 XX 倍` → subscription_ratio

## ⚠️ 已知局限

1. **冷门大盘股**：顺丰/金山云这类强基石仍破发，模型无法预测市场情绪
2. **暗盘数据缺失**：暗盘表现是更重要的参考
3. **PE 数据缺失时**：无低估/高估加成
4. **数据来源依赖**：财经媒体搜索，准确性由搜索质量决定
5. **召回率偏低**：约 52% 的上涨股被错过（保守策略）
